#Тема 11: Развертывание и настройка реляционной базы данных PostgreSQL

#Описание проекта
Данный репозиторий содержит инфраструктуру для развертывания безопасной и оптимизированной СУБД PostgreSQL в среде Docker.

#Роль: Docker Infrastructure & Security Engineer
В рамках проекта реализованы следующие механизмы:
1. **Docker Compose манифест**: Использование минимального образа `alpine`, именованных томов и изолированных сетей.
2. **Docker Secrets**: Полный отказ от передачи мастер-пароля в открытом виде через переменные окружения.
3. **Ограничение ресурсов**: Настройка `mem_limit` и `cpu_quota` для предотвращения OOM killer.
4. **Health Check**: Интеграция `pg_isready` для контроля жизнеспособности контейнера.

#Инструкция по запуску
1. Скопируйте `.env.example` в `.env` и заполните переменные.
2. Создайте файл секрета: `echo "your_password" > deploy/secrets/db_password.txt`
3. Перейдите в папку deploy: `cd deploy`
4. Запустите инфраструктуру: `docker compose up -d`
